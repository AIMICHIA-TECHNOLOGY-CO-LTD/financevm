## FinanceVM 是什麼

FinanceVM 是專為金融資產代幣化而建的主權標準合規虛擬機。它立基於一個前提：**定義一項資產的權威來源是金融合約本身，而非代幣標準。**

合約被表述為結構化、可計算的 ACTUS 條款集。FinanceVM 由這單一份已簽章的來源確定性地導出下游的一切——帳本狀態、ISO 20022 電文、會計分錄、監理指標，以及智能合約本身。因為五者皆源自同一份條款集而非各自維護，它們天然一致，彼此之間不需要對帳。

每個機構運行自己的主權節點。節點之間不共享全域狀態，而是各自對同一份已簽章的合約條款負責。這是主權國家網路，不是單一世界狀態。

**FinanceVM 不取代帳本。** 它補上通用帳本從未被設計來承擔的金融執行層，並還原通用帳本所混同的分工：合約在能保證精度與標準之處計算，帳本則記錄狀態與提供存證。

## 要解決的問題

以鏈上運算執行複雜金融邏輯，並不適用於此項工作，原因有三。

| 問題 | FinanceVM 的解答 |
|---|---|
| **精度**——通用帳本不提供原生高精度十進位運算，捨入誤差因此進入不容許誤差的計算 | 任意精度算術核心，零浮點誤差 |
| **成本**——執行成本使蒙地卡羅選擇權定價一類的風險模型難以於鏈上運行 | 計算置於鏈下；帳本記錄結果而非運算過程 |
| **金融語意**——代幣介面描述的是可轉讓性而非金融語意，於程式碼與法律合約之間留下落差 | 工具由 ACTUS 條款與金融物件模型（FINOS CDM 與 ISO 識別碼標準）定義 |

## 架構概覽

| 模組 | 標準 | 職責 |
|---|---|---|
| **精度核心** | — | 任意精度算術，支撐全部計算 |
| **FOM** | FINOS CDM、ISO 4914、6166、10962、18774、20275、23897、24165 | 這是什麼工具 |
| **BPoS** | ISO 21586 | 這個產品應如何運作；控制基準線 |
| **ACTUS** | ACTUS | 這份合約在存續期間會產生什麼 |
| **FEK** | ISO 17442-3、ERC-3643、ISO 20022、ACTUS | 合規控制：四道關卡加雜湊鏈接稽核軌跡 |
| **ISO 20022** | ISO 20022 | 電文組裝與驗證 |
| **vLEI** | ISO 17442-3（KERI/ACDC） | 機構身分 |
| **BCBS SCO 60** | Basel III | LCR / NSFR |
| **PQC** | NIST FIPS 203 / 204 | ML-KEM-768、ML-DSA-65 |

FEK 為合規控制模組。其四道關卡——身分、轉讓規則、電文、生命週期——皆可插拔，能依部署的帳本或適用的監理法規註冊替代實作。生命週期關卡刻意鎖定 ACTUS，因為它是溯源鏈的錨點。

## 專案狀態

FinanceVM 目前並行兩條軌道，評估本專案時此區分至為重要。

| | Showcase Track | Reference Track |
|---|---|---|
| 標示 | `v1.x — Sandbox` | `v2.0 — Reference Implementation` |
| 內容 | 十類金融工具沙盒平台：存款、債券、股票、期貨、選擇權、抵押品、大宗商品、SWAP、年金、保證 | 於 Hyperledger Besu 重構之平台 |
| 用途 | 展示同一核心橫跨各類金融工具的可移植性 | 正式合作、監理對話、能力評估標的 |

沙盒平台為能力展示產物。**其非白皮書所述能力評估之標的**；該評估適用於目前正在重構的 Reference Implementation。

另有兩項範圍聲明：

- **尚未發布自評分數。** Reference Implementation 正在重構，對一個即將被取代的架構給出分數將產生誤導。重構完成後，將依 0–4 分證據制對 32 個建構區塊發布完整自評。詳見白皮書第 11 節。
- **後量子密碼已實作但尚未取得認證。** PQC 模組已實作 FIPS 203/204；在認證完成前，不宣稱後量子合規。

跨帳本原子結算為主動緩議項目，待各管轄權監理機關對公鏈參與提出更明確方向後再行實作。白皮書第 5.4 節載明合約定錨機制解決什麼、不解決什麼。
